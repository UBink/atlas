# Atlas

A lightweight tool to visualize and understand code repository structure.

## Installation
```bash
git clone https://github.com/UBink/atlas.git
cd atlas
```

## Usage
```bash
python atlas.py
```

Enter a directory path when prompted, and Atlas will display the file structure.

## Example Output
```
my-project/
├── src/
│   ├── main.py
│   └── utils.py
├── tests/
│   └── test_main.py
└── README.md
```
